# Electric Jamez - Electrical Services Website

A modern, responsive website for Electric Jamez, a NAPIT-approved electrician based in North West London (NW2). Built with Next.js 14+ and TypeScript, featuring smooth animations, interactive components, and a professional design tailored for electrical services.

## About

Electric Jamez provides professional electrical services including:
- EV charger installation
- Air conditioning installation
- PAT testing
- Electrical safety certificates  
- General electrical work

The website showcases services, displays a photo gallery, includes an interactive map, contact forms, and more - all designed to convert visitors into customers.

## Features

- **Modern UI/UX**: Clean, professional design with smooth animations
- **Responsive Layout**: Mobile-first design that works on all devices
- **Interactive Components**: 
  - Animated service cards
  - Interactive map section
  - Photo gallery
  - FAQ accordion
  - Chat assistant
- **Performance Optimized**: Fast loading times and SEO-friendly
- **Accessibility**: WCAG compliant design practices
- **Contact Integration**: Easy contact forms and call-to-action buttons

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 16.1.7
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **UI Components**: Lucide React icons
- **Maps**: Google Maps React
- **Analytics**: Vercel Analytics
- **Deployment**: Vercel

## Getting Started

First, install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
